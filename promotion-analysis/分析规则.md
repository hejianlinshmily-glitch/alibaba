# 1688 推广询盘分析规则 v1.1

KA方案主指标为原表“有效询盘量”；全站推店使用原表“询盘量”，不将其改称有效询盘量。一个分析周期由店铺、推广方式、开始日期、结束日期共同确定。下文“询盘量”指当前推广方式的对应口径。

## 基线与指标

- 当期基线 T = 完整表格总消耗 / 完整表格总询盘量。
- 商品询盘成本 = 商品消耗 / 商品询盘量。
- 成本相对值 = 商品询盘成本 / 当期基线。
- 整体平均点击成本 = 总消耗 / 总点击次数。
- 点击率 = 总点击次数 / 总展现次数。
- 询盘转化率 = 总询盘量 / 总点击次数。
- 零询盘商品的消耗保留在基线分子内。
- KA有效询盘和有效线索不相加；全站询盘量、线索量、优质询盘量不相加，不将次数解释成跨商品去重客户人数。
- 不平均商品行里的比率、平均点击成本或询盘成本。

## 三条固定规则

1. 筛选、搜索商品时，基线保持不变，始终使用该店铺该推广方式该周期完整表格计算。
2. 多周期对比时，各期使用各自基线，同时展示实际成本变化。
3. 商品零询盘时标记“暂无询盘”，不显示0元成本。

## 分类顺序

按照以下顺序判断，一款商品只属于一个类别。

| 顺序 | 类别 | 条件 |
| --- | --- | --- |
| 1 | 尚未消耗 | 消耗为0 |
| 2 | 高消耗无询盘 | 有消耗、询盘为0、点击≥30、消耗≥2T |
| 3 | 样本不足 | 点击<30，或者询盘<5 |
| 4 | 成本较低 | 满足样本门槛且询盘成本≤0.8T |
| 5 | 成本正常 | 满足样本门槛且0.8T<询盘成本≤1.5T |
| 6 | 成本偏高 | 满足样本门槛且询盘成本>1.5T |

边界包含：30次点击、5次询盘进入成本比较；0.8T归成本较低，1.5T归成本正常。

## 导入与比较

- KA读取“消耗、点击次数、有效询盘量”；全站读取“消耗量、点击量、询盘量”。全站线索量与优质询盘量仅保留供查看。
- 表中合计、总计、汇总行跳过，避免与商品行重复计入。
- 按商品ID匹配商品，标题修改不改变商品身份。
- 一个工作表内商品ID重复时提示检查，不擅自合并。
- 同店铺、同推广方式、同开始日期同结束日期再次导入时替换，不叠加；KA与全站不互相覆盖。
- 上传前由用户选择所属店铺，不从不含店铺名称的表格自动猜测。支持新增店铺、全店重命名、单份记录修改所属店铺；只修改归属时不改变原始商品数据及基线。目标存在相同推广方式和周期时，拦截修改以避免覆盖。
- 不同店铺、不同推广方式记录分开。周期对比仅选择同店铺、同推广方式；日期重叠的周期不合并累计。
- 缺失必需字段、空消耗或空计数不当作0处理。
- 每次导入重算基线及分类；不因局部商品筛选改变基线。
- 对比期长度不同时提示天数，不将总量差异直接解释为效率变化。
- 历史原始数据保留，分类按当前规则版本重新计算；导出记录当前规则及基线。

## 历史清空

“清空历史 / 回到初始界面”需点击确认；只删除本页面的店铺名单、推广记录和当前筛选，不删除原始Excel或其他网页的数据。提供先备份入口；兼容旧版KA历史和备份。

## 文件与版本

规则常量在 src/content/shared/rules.mjs 的 RULES 中统一保存。调整门槛时同时修改版本号、本文及对应测试，重新构建后发布。

平均水平是当期内部比较依据；分类用于决定复核顺序，页面不自动修改1688预算或推广开关。

## 长期历史统计

按店铺、推广方式筛选已导入周期，各期基线独立，按日期列出真实成本及相对上一导入周期的变化。商品筛选不影响历史统计。
互不重叠时：已导入历史整体询盘成本=所选周期消耗总和÷询盘总和，不平均各期成本。存在日期重叠时不累计。历史整体成本只作历史统计，不用于商品分档；日期有空缺时不视为连续完整数据。
固定样本只含虚拟数据，固定v1以后不覆盖；长期版保存用户导入记录，按原有重复导入键更新。
