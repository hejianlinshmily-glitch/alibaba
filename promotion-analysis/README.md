# 1688推广询盘分析

- [固定样本v1](sample-v1/)：固定规则与虚拟演示数据，仅供查看验证，不保存经营历史。
- [长期统计版](live/)：日常新增店铺、导入KA或全站表、历史统计、周期对比、导出与备份。

固定sample-v1目录及frozen.json不可覆盖。新样本另建sample-v2。长期工具路径live保持不变，后续只更新live与源码包；用户导入历史仍在浏览器，同店铺、同推广方式、同周期重复导入替换。

首次从离线HTML迁移：旧页面备份历史，在live页面恢复。以后收藏live网址，先选店铺，再导入本期完整表格。换电脑或浏览器需备份与恢复；GitHub不自动同步经营数据。

各期基线独立。历史日期有重叠时不累计，日期有空缺时累计只代表已导入周期。真实Excel、备份和经营报告不要提交到公开仓库。

源码见template-source.zip，解压后让Codex先读AGENTS.md、README.md及分析规则.md；保留冻结样本。修改后完成规则与交互验证再更新live。
